### 2.3. Основные переменные и вспомогательные функции
Для хранения состояния калькулятора объявлены переменные:

```js
let a = '';                // первое число (строка)
let b = '';                // второе число (строка)
let selectedOperation = null; // выбранная операция: '+', '-', 'x', '/'
```

Для удобной работы с текущим числом созданы две функции:

- `getCurrentNumber()` – возвращает строку того числа, которое в данный момент редактируется (если операция не выбрана – `a`, иначе – `b`).
- `setCurrentNumber(value)` – обновляет соответствующую переменную и выводит значение на экран, применяя правила форматирования и проверку длины.

```js
function getCurrentNumber() {
    return selectedOperation ? b : a;
}

function setCurrentNumber(value) {
    if (selectedOperation) {
        b = value;
    } else {
        a = value;
    }

    let displayStr;
    if (value === 'Ошибка') {
        displayStr = 'Ошибка';
        a = ''; b = ''; selectedOperation = null;
    } else if (value.length > 16) {
        displayStr = 'BIG NUMBER';
    } else {
        displayStr = value === '' ? '0' : value;
    }
    outputElement.innerHTML = displayStr;
}
```

### 2.4. Обработка ввода цифр и точки
Все цифровые кнопки (0–9) и кнопка точки выбраны с помощью селектора `[id ^= "btn_digit_"]`. Для каждой из них назначен обработчик, который вызывает функцию `onDigitButtonClicked(digit)`.

```js
function onDigitButtonClicked(digit) {
    let current = getCurrentNumber();

    // Если на экране сообщение об ошибке – сбрасываем состояние
    if (current === 'Ошибка') {
        current = 0;
        a = ''; b = ''; selectedOperation = null;
        outputElement.innerHTML = '0';
    }

    // Защита от ввода второй точки
    if (digit === '.' && current.includes('.')) return;

    // Запрет ввода лидирующих нулей (например, 012 → 12)
    if (digit === '0' && current == 0) return;

    // Ограничение длины ввода: не более 16 символов
    if (current.length >= 16) return;

    current += digit;
    setCurrentNumber(current);
}
```

### 2.5. Основные арифметические операции
Для кнопок `+`, `-`, `×`, `÷` реализована общая функция `setOperation(op)`, которая устанавливает `selectedOperation`, но только если первое число уже введено.

```js
function setOperation(op) {
    if (a === '') return;
    selectedOperation = op;
}
```

Кнопка `=` выполняет вычисление:

```js
equalBtn.onclick = () => {
    if (a === '' || b === '' || !selectedOperation) return;

    let numA = parseFloat(a);
    let numB = parseFloat(b);
    let result;

    switch (selectedOperation) {
        case '+': result = numA + numB; break;
        case '-': result = numA - numB; break;
        case 'x': result = numA * numB; break;
        case '/':
            if (numB === 0) {
                setCurrentNumber('Ошибка');
                return;
            }
            result = numA / numB;
            break;
        default: return;
    }

    a = result.toString();
    b = '';
    selectedOperation = null;
    setCurrentNumber(a);
};
```

Также реализованы:
- **Очистка (C)** – сбрасывает `a`, `b`, операцию и выводит `0`.
- **Смена знака (±)** – умножает текущее число на `-1`.
- **Процент (%)** – делит текущее число на `100`.

### 2.6. Дополнительные функции: квадрат и квадратный корень
Согласно индивидуальному заданию, из всех предложенных дополнительных операций были реализованы **возведение в квадрат** (`x²`) и **квадратный корень** (`√`). Обе функции работают с текущим числом, сохраняют результат как новое первое число и сбрасывают операцию.

```js
squareBtn.onclick = () => {
    let current = getCurrentNumber();
    if (current === '') return;
    let num = parseFloat(current);
    let result = (num * num).toString();
    a = result;
    b = '';
    selectedOperation = null;
    setCurrentNumber(a);
};

sqrtBtn.onclick = () => {
    let current = getCurrentNumber();
    if (current === '') return;
    let num = parseFloat(current);
    if (num < 0) {
        outputElement.innerHTML = 'Ошибка';
        return;
    }
    let result = Math.sqrt(num).toString();
    a = result;
    b = '';
    selectedOperation = null;
    setCurrentNumber(a);
};
```

### 2.7. Переключение дополнительной панели
Для экономии места на экране кнопки с дополнительными функциями (`√` и `x²`) размещены в отдельном блоке `extraPanel`, который по умолчанию скрыт. Кнопка переключения (символ `▶`) при нажатии показывает панель и меняет символ на `▼`, повторное нажатие скрывает панель.

```js
const extraToggle = document.getElementById('btn_extra_toggle');
const extraPanel = document.getElementById('extraPanel');

extraToggle.onclick = () => {
    if (extraPanel.style.display === 'none') {
        extraPanel.style.display = 'block';
        extraToggle.textContent = '▼';
    } else {
        extraPanel.style.display = 'none';
        extraToggle.textContent = '▶';
    }
};
```

### 2.8. Ограничение ввода и вывод BIG NUMBER
Для удобства работы с большими числами введены два ограничения:
- **Ввод** – пользователь не может набрать число длиннее 16 символов (проверка в `onDigitButtonClicked`).
- **Вывод** – если результат вычисления (или введённое число) в виде строки имеет длину более 16 символов, на экран выводится сообщение `BIG NUMBER`. Само число при этом сохраняется в переменных `a` или `b` и может использоваться в дальнейших операциях.

Это реализовано в функции `setCurrentNumber`:

```js
if (value.length > 16) {
    displayStr = 'BIG NUMBER';
} else {
    displayStr = value === '' ? '0' : value;
}
```
