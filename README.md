## 2. Выполнение работы

### 2.1. Создание базовой структуры проекта
- `index.html` – заглушка главной страницы (с навигацией на калькулятор).
- `calculator.html` – страница с калькулятором.

### 2.2. Выполненные задания

#### 1. Замена цветовой палитры
В соответствии с сайтом-родителем изменены основные цвета: кнопки операций получили оранжево‑красные оттенки (`#ff2f00`, `#fc613f`), фон контейнера калькулятора стал светло‑голубым (`#c9dced`), а кнопки с цифрами остались белыми.

Пример стилей для кнопок:
```css
.my-btn.primary { background: #ff2f00; }
.my-btn.secondary { background-color: #fc613f; }
.calculator-container {
  background-color: #c9dced;
  border-radius: 12px;
  padding: 20px;
  box-shadow: 0 10px 20px rgba(0, 0, 0, 5);
}
```

#### 2. Возможность смены фона (тёмная тема)
Добавлена кнопка **«Сменить фон»**, при нажатии на странице калькулятора переключается класс `dark-theme` у тега `body`. Для этого класса задано другое фоновое изображение (`фон2.png`). Скрипт переключения расположен непосредственно в `calculator.html`.

HTML-кнопка:
```html
<button id="theme-toggle" class="theme-btn">Сменить фон</button>
```
CSS-правило:
```css
body.dark-theme {
  background-image: url("images\\фон2.png");
}
```
JavaScript:
```js
const themeToggle = document.getElementById('theme-toggle');
themeToggle.addEventListener('click', () => {
  document.body.classList.toggle('dark-theme');
});
```

#### 3. Форма кнопок
Кнопки изменены с круглых на квадратные со скруглением углов (`border-radius: 12px`). Для кнопки «=» дополнительно задана увеличенная ширина и большее скругление (`border-radius: 34px`), что визуально выделяет её.

```css
.my-btn {
  border-radius: 12px;
  border: none;
  width: 50px;
  height: 50px;
  /* ... */
}
.my-btn.execute {
  width: 110px;
  border-radius: 34px;
}
```

#### 4. Скругление окна вывода
Поле вывода результата также получило скругление `12px`, что делает его единообразным с кнопками.

```css
.result {
  width: 220px;
  height: 50px;
  border-radius: 12px;
  /* ... */
}
```

#### 5. Дополнительное задание: везде шрифт italic
Преподавателем было дано дополнительное требование: установить курсивное начертание для всех элементов страницы. Это реализовано с помощью универсального селектора `*` в начале файла стилей:

```css
* {
  font-style: italic;
}
```

Благодаря этому правилу все тексты на страницах (включая заголовки, кнопки, поля вывода) отображаются курсивом, за исключением тех элементов, где курсив может быть переопределён более специфичными селекторами (но в проекте таких переопределений нет).

### 2.3. Структура навигации
На обеих страницах присутствует логотип «РосТендер» (стилизованные части `ros` и `tender`) и кнопка перехода между страницами. Логотип и навигационные кнопки зафиксированы в левом верхнем углу для удобства пользователя.

```css
  position: fixed;
  top: 12px;
  left: 12px;
  font-family: Arial, Helvetica, sans-serif;
  font-size: 22px;
  font-weight: 700;

.nav-btn {
  position: fixed;
  top: 12px;
  left: 150px;
  /* ... */
}
```
