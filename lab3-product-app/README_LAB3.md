# ЛР 3 — готовый проект

Тема варианта: **продукты**  
Обязательный bootstrap-компонент: **badge (значки)**

## Что внутри
- главная страница со списком карточек
- вторая страница продукта
- структура `pages` и `components`
- рендер через JavaScript
- подключение bootstrap через npm

## Как запустить
1. Открой папку проекта в VS Code.
2. Открой терминал в этой папке.
3. Выполни команду:
   ```bash
   npm install
   ```
4. После установки зависимостей запусти через Live Server файл `index.html`.
